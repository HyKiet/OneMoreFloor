# Balloon icons

Created on 2026-10-12 for Pump a Balloon to Space using the built-in image_gen tool.

- 11 individual PNG icons: Party, Big, Weather, Hot Air, Blimp, Rocket, Star, Galaxy, Void, Angel, and Inferno Dragon.
- Actual output dimensions: 1254 x 1254 pixels (1:1), RGBA with transparent backgrounds.
- Dark navy outlines, bright cartoon colors, compact cel shading, and simplified model silhouettes follow the existing Icon collection.
- Open index.html locally to compare every icon at 64, 128, 256, or 384 px on light or dark backgrounds. This preview does not change the PNGs.
- prompts.json records every generation prompt and its style/model references. validation.json records image dimensions and alpha checks.
- Requested model name: "GPT Image 2.5 Sunburst". The built-in tool exposes no model selector and does not report its actual model identifier; use of that specific model is unverified.
- Style references come from the existing Icon collection by @gvesster. Its original license is in ../License.txt.
- Ten regular balloon icons have been uploaded by the user and connected to the shop, goal HUD, and flight result UI. roblox_asset_ids.json records their IDs; Core/Icons.luau is the runtime source of truth. Inferno Dragon has no uploaded image ID yet.
